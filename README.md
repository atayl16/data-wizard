# Data Wizard (QA Automation Tool)

Internal-use app originally built at MyTime to speed up QA setup for merchant accounts. Still in use years later due to its reliability and time-saving impact.

## Features
- One-click creation of merchant test accounts
- Pre-loads service data, appointments, and location settings
- CSV export of sandbox test configs

## Stack
- **Backend**: Ruby on Rails (classic MVC)
- **Frontend**: Embedded ERB + vanilla JS
- **Storage**: PostgreSQL

## Usage
Only usable internally by MyTime staff. Clone and run locally with limited sandbox access.

## Impact
Saved up to 3 hours of setup time per QA cycle. Still used 5+ years later.
